# Phishing Email Analysis Lab

## Overview
This project demonstrates basic phishing email analysis and identification of common social engineering tactics used in credential theft attacks. The lab focused on recognizing phishing indicators, suspicious messaging techniques, and impersonation attempts commonly observed in malicious emails.

## Tools Used
- Web Browser
- Public Phishing Email Examples
- GitHub
- Windows 11

## Objectives
- Identify phishing indicators in suspicious emails
- Analyze social engineering techniques
- Recognize urgency and impersonation tactics
- Understand credential harvesting attempts
- Document phishing analysis findings

## Phishing Indicators Identified
- Suspicious security/login alert language
- Urgent call-to-action messaging
- Brand impersonation attempts
- Potential credential harvesting behavior
- Social engineering manipulation tactics
- User pressured to click links quickly

## Analysis Performed
The phishing email example was reviewed to identify common tactics attackers use to manipulate users into revealing credentials or interacting with malicious links.

The analysis focused on:
- Sender impersonation
- Emotional urgency
- Security scare tactics
- Fake login/security notifications
- User interaction pressure

## Key Concepts Learned
- Social Engineering
- Phishing Attacks
- Credential Harvesting
- Email Threat Analysis
- Brand Impersonation
- User Manipulation Tactics
